# 実メール用の内蔵検査実験版（0.20.0a5）

このブランチの実験版は、現行の画面・受信検査・フォルダー検査・履歴・確認メモ・通知・隔離・完全削除を、アドオン内蔵の検査処理へ接続します。合成メール専用の0.1.0試作とは別の成果物です。

## 利用条件と導入

- Ubuntuの通常版Thunderbird 153系を対象にしています。153.7.0esrで検証しました。Snap/Flatpak、他OS、他のメジャーバージョンは未検証です。
- OSにClamAVとPython3が必要です。新しいライブラリやサービスの追加インストールは行っていません。
- 検証済みのPython検査処理をXPIに同梱し、Python3で必要時に起動します。補助プログラムの別途設置・Native Messaging登録・個別更新は不要です。
- Experiment APIを使うため、インストール時にはThunderbirdとコンピューターへの全面アクセス権限が必要です。完全削除・手動隔離などの確認画面は維持しています。
- 旧版を削除せず、実験版のXPIを上書きインストールします。同じアドオンIDを維持し、既存の設定・履歴を引き継ぎます。新規インストール時の自動検査は無効です。
- 以前の補助プログラムと接続登録は使用・変更・削除しません。安定版へ戻す場合に備えて残します。

最初は少数のメールを手動検査し、設定末尾のClamAVの状態と既存の履歴・設定を確認してから利用してください。

## 画面

「検査・検査結果・設定・ヘルプ」の4タブです。ClamAVの状態は設定の末尾にまとめ、接続エラー時は設定タブの丸印と状態欄で案内します。更新・削除の手順はヘルプへ簡潔に記載します。独立したセットアップ/アンインストールタブや、移行用の常設案内は設けません。

## バックアップと削除

既存の設定や履歴がある場合、実験版の初回起動時に、移行前の状態をThunderbirdプロファイル内へ別ファイルで保存します。バックアップに失敗した場合は移行を進めません。バックアップの作成・保持は維持しますが、保存場所は画面に常設表示しません。履歴の差出人・件名・判断メモ等を含みますが、本文・添付は含みません。

アドオンを削除しても、このバックアップと、OSのClamAV・Python3・旧版の補助プログラムは残ります。アドオンの通常の設定・履歴・再開情報は、削除で失われる可能性があります。バックアップの自動消去や自動復元は実装していません。

## 検証

- JavaScript170件、Python69件（計239件）。従来のNative Messaging方式のテストも継続しています。
- 日英の模擬UI：4タブ構成・設定内のClamAV状態・接続エラーの通知と動線・キーボード操作・任意権限要求なしの操作・削除確認・狭幅表示を確認。従来方式の日英UIも通過。
- 実Thunderbirdと合成のローカルメール：旧形式の設定・確認メモの移行、バックアップ、フォルダー検査、通常/EICAR添付/ZIP/暗号化の判定、確認メモ付きの再検査、手動隔離・完全削除、新着の自動検査・自動隔離、カスタム設定の適用を確認。
- 実験版同士の更新後も設定・履歴を引き継ぎ、更新・Thunderbird強制終了後に検査プロセスと一時ファイルが残らないことを確認。
- 普段の環境・実メール・旧補助プログラムは未変更です。実際の導入時の権限画面は、利用時に確認してください。

## 再現コマンド

リポジトリのルートから実行します。

```bash
python3 -B scripts/build_direct_mail_check.py
python3 -B scripts/smoke_direct_mail_check.py
node scripts/smoke_mail_ui.mjs --direct
```

ビルド結果は `dist/clam-mail-check-direct-0.20.0a5.xpi` です。テスト用のメール取り込み・自動更新・診断APIはこの配布物へ含めません。実機検証は独立Wayland・D-Bus・XDG設定と使い捨てプロファイルを使用し、Thunderbirdはオフラインで起動します。実画面の操作・Xwayland・リモート操作用の権限変更は使いません。

詳細な診断結果はGit除外の出力先へ、監視処理の詳細は非公開の作業メモへ保存しています。公式アドオンサイトへの公開・申請は行っていません。独自Experiment APIの公開条件については引き続き確認が必要です。

## 再検査の失敗時（0.20.0a3）

再検査が失敗しても前回の結果を保持し、今回の失敗理由を併記します。同じ本文での脅威検出は維持し、隔離できます。本文が変わっていた場合は前回の結果を参考情報として残し、現在の本文で検出した扱いにはしません。「検査失敗」の絞り込みでも確認できます。再検査で確定した新しい結果が得られれば更新します。

## フォルダー検査前の状態確認（0.20.0a4）

開始・再開の直前にClamAVの状態を確認します。未導入や通信不能の場合は検査を開始せず、設定内の状態欄へ移動します。履歴と停止中の進捗は保持します。導入後は改めて開始・再開でき、過去の確認結果だけで開始を許可しません。
